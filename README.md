💰 Sistema de Desconto

Programa desenvolvido em Python que calcula o desconto de uma compra de acordo com o valor informado.

📌 Regras:

Menos de R$ 200 → 5% de desconto

De R$ 200 a R$ 299,99 → 10% de desconto

R$ 300 ou mais → 15% de desconto

🛠️ Tecnologias

Python 🐍

▶️ Como executar

Execute o arquivo Python e informe o valor da compra quando solicitado.

O programa mostrará:


° Porcentagem do desconto

° Valor do desconto

° Valor final da compra
